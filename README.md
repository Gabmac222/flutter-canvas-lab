# Flutter Canvas Lab

**[Open the visual Flutter designer](https://gabmac222.github.io/flutter-canvas-lab/)**

Build a Flutter screen, explore widgets and icons, try interactions, watch beginner demos, and export a complete Dart project for VS Code.

This repository contains the published website only. Development files, tests, examples, and source history are maintained separately. Website updates are generated automatically after testing.

Fonts and icons retain their license notices in `assets/`.
